## 🏗️ Active Project: Onboard.track

> **ERP Client Onboarding Dashboard** — answers "Is this client ready to go live?" in under 10 seconds without opening a spreadsheet.

**Stack:** Next.js 14 + Supabase + Tailwind CSS + Vercel  
**Build Time:** 8 weeks to MVP  
**Status:** PRD complete → Next: Figma Wireframes

### 5 MVP Features
1. Project Setup & Client Dashboard
2. Module Progress Tracker (7-stage pipeline)
3. Sign-off Workflow (client approves via email link — no login needed)
4. Client Readiness Score (0–100%)
5. Team Daily View (personalized "what needs my attention today")
